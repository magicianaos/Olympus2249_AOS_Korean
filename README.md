# 올림푸스 2249(Olympus 2249) 한글패치

Steam 게임 **Olympus 2249**(얼리 액세스) 비공식 한국어 패치입니다.

## 받기
👉 **[최신 버전 받기 (Releases)](https://github.com/magicianaos/Olympus2249_AOS_Korean/releases/latest)**

- `Olympus2249_KR_Patch_Beta(버전).exe` — 한글패치 런처 (설치·되돌리기·제보하기)
- `Olympus2249_KR_Review_Beta(버전).xlsx` — 검수표 (선택)

## 설치
1. Steam을 켜고 게임을 구매한 계정으로 로그인, 게임은 종료
2. 런처 실행 → **[패치 설치하기]** (원본 확인 때문에 1~2분)
3. 게임 실행하면 한국어로 표시 (언어는 English·中文 어느 쪽이든 한국어)

되돌리기: 런처의 **원래대로 되돌리기** (추가한 한글 PAK 파일만 지웁니다)
